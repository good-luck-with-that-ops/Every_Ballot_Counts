READING THE MAP
Follow the red. The inputs the court record describes (state rolls, DOJ’s 50.6M, the 48.2M “independent” records, commercial data) enter through DHS headquarters and USCIS’s fraud unit and become TECS records. TECS is already an input to PCIS, USCIS’s one-profile-per-person index, which sits on the same data layer as a lake with an entity-resolution graph built “for investigators.” No court order names PCIS or the data lake. Whether voter data is stored there is not shown. The PCIS privacy assessment calls its index a “single, trusted source.”
INSPECTORS GENERAL · THE HUB’S PARTNERS
The matching exemption
A data match run by an inspector general, or by any agency “in coordination with” one, during an audit or investigation “shall not be considered a matching program” (IG Act §6(j), added 2016). No matching agreement, no Federal Register notice, no independent check or notice to the person before adverse action. IG data requests are also exempt from the Paperwork Reduction Act (§6(k)). D
